# Repository metadata

## GitHub About description

Maintainers should set the repository **Description** (Settings → General → Description) to something like:

> Arabic knowledge platform — videos, books, articles, research, team dashboard, and AI assistant.

Do **not** use the stale notes-app wording:

> A full-stack notes application — create, search, edit, and delete notes.

Automation cannot always change the GitHub About field; this is a maintainer UI action (issue #11).
